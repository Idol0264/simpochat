# SimpoChat Starter

Mobile-first visual foundation for SimpoChat.

## Included
- Group-first Home screen
- Posts entry and prototype Posts grid
- Archived / Home / Starred icon-only navigation
- New Group flow with maximum 3 categories
- Search existing groups / join flow placeholder
- Settings with System / Light / Dark theme
- Animated ambient "waving light" background
- Glass-style surfaces and responsive layout
- Tally-ready visual container for later embedded forms
- No Supabase, authentication, or external dependency yet

## Upload
Extract the ZIP and upload the contents to the `main` branch of the `Idol0264/simpochat` repository.

The main entry point is `index.html`.

## Next build stage
Connect the visual shell to the actual group/chat/post data model, then add Supabase realtime/storage and the agreed temporary-chat/call rules.
